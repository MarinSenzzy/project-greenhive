# 🌿 EcoTote — сайт бренду еко-сумок

## Про проєкт

На реалізацію проєкту було відведено **8 днів**.

Основна ідея полягала у створенні вебсайту для користувачів, які цінують **естетику, практичність і свідоме споживання**.  
Мета — поєднати **стильний зовнішній вигляд** із **турботою про довкілля**, популяризуючи еко-спосіб життя та відповідальне ставлення до природи.

Сайт презентує бренд **еко-сумок**, виготовлених з **органічних та вторинних матеріалів**.

## 🧩 Основний функціонал

- Головна сторінка з описом бренду та його філософії  
- Каталог товарів із фото та коротким описом  
- Адаптивна верстка для мобільних пристроїв  
- Контактна форма для зв’язку з брендом

## 💬 Як проходила робота

На початку команда отримала **готовий макет однієї сторінки**.  
Перші дні були трохи хаотичні — не могли визначити ролі, тому **Team Lead взяв ініціативу на себе**.  
Після цього Scrum Master організував роботу через **Trello**, де кожен отримав власні секції сайту.

Команда проводила **стендапи через день**, обговорювала прогрес і допомагала один одному з HTML та CSS.  
Незважаючи на те, що **деякі учасники не завжди були активними**, проєкт вдалося завершити вчасно.  
Було непросто, але це дало цінний досвід **справжньої командної роботи та планування**.
